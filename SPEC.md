# SPEC

## §G GOAL

`actlith` (cmd `actlith`) — GitHub Actions workflow MATERIALIZER: from small `.actlith` (1 row = 1 workflow: id, kind, systems, cache, args) RENDER full `.github/workflows/*.yml` + seeded scripts; ∀ action SHA-pinned; hardening ⊥ optional; CHECK committed files == render (drift) & ∀ workflow file declared (totality). purely mechanical: ⊥ LLM, ⊥ inference, ⊥ network (sole exception `actlith pin`, opt-in).

PAIR: pklith decides WHAT is checked (hk gate); actlith decides WHERE & WHEN CI runs it. actlith ⊥ adds lint steps.

WHY: fleet = 163 hand-copied `ci.yml`, copies drift (R1). variable part = few values ∴ shape from 1 place.

NAME: act(ions) + lith — fleet family `pklith`, `microlith`, `xenolith` (V22).

FIRST BUILT: this repo's own guardrails (`nix` T2–T12), 1 check per commit, hooks live from hk commit — before any product code.

SOURCES: `SPEC-PROMPT.md` (decisions D1–D23), `docs/KINDS.md` (kind catalogue) & `docs/SERVICES.md` (third-party services: adopt free, paid = potential). this spec wins where they differ.

FEDERATED (T34): rules & tasks moved to a node keep their numbers ∴ freed numbers ⊥ reused here.

## §C CONSTRAINTS

- deterministic core: same `.actlith` + same actlith version → byte-identical output. ⊥ LLM, ⊥ heuristic guess, ⊥ clock | rng | hostname in output, ⊥ network except `pin` (V1).
- lang: Rust edition 2024, stable, MSRV 1.95 = fleet pin (`nixpkgs-lock` → nixos-26.05). MIT. `unsafe_code = "forbid"` (⊥ FFI need).
- layout: ONE published crate `actlith` (lib + bin `actlith`, same name ∴ `cargo install actlith` gives the cmd); `dev/` = `actlith-dev`, `publish = false`. module = dir + `mod.rs` = node.
- deps minimal; ∀ dep ! justified in §R & owned by ONE facade node. `clap` (derive) → `src/cli`. YAML WRITTEN by own writer (`src/yaml`); YAML reader only if research proves render-and-compare insufficient (`src/import`).
- kinds = typed Rust data ∈ actlith, ⊥ text templates. v1 kinds: `gate` `build` `update-pins` `upstream` (`docs/KINDS.md`). ⊥ repo-defined kinds in v1 ∵ typed kinds ⊥ come from config ∴ need → `## hand-written` row, upstream kind once 2 fleet repos share shape (V24).
- seeded scripts (`scripts/actlith/*.sh`) = GENERATED by `gen` (header, drift-checked), ⊥ repo-owned skip-if-exists like pklith seed. `seed --init` writes only first `.actlith`.
- runtime deps: `git`. `actionlint`, `zizmor` = test & gate deps, ⊥ runtime.
- TDD RED → GREEN → REFACTOR. 1-to-1 unit coverage, hard floor + `.coverage` ratchet, aim 100%.
- ⊥ push | PR to another repo w/o explicit approval. ⊥ name private fleet repo in committed file; check `gh repo view` first.
- spec: caveman, sections per `FORMAT.md` + `FORMAT-EXTENSIONS.md`, federated per sherd; `§N` generated by `sherd sync`.

## §I INTERFACES

- cmd: `actlith gen [--root DIR] [--check]` → write `.github/workflows/<id>.yml` ∀ row & `scripts/actlith/*.sh` the kinds need. `--check` writes ⊥, exit 1 naming each stale | missing file
- cmd: `actlith check [--root DIR]` → totality: ∀ file ∈ `.github/workflows/` generated | `## hand-written`; ⊥ listed path missing; ⊥ generated file w/o row
- cmd: `actlith detect [--root DIR]` → proposed `## workflows` rows from tracked files (`flake.nix` → `gate`; `nixpkgs-lock` input → `update-pins`), 1 per line, stdout
- cmd: `actlith seed --init` → first `.actlith` from `detect`; ⊥ over existing file
- cmd: `actlith import FILE…` → `.actlith` row per workflow that matches a kind, stdout; ⊥ match → exit 1 naming first differing key
- cmd: `actlith report [--format text|json|md]` → workflow × system × action@pin, secrets per workflow. json versioned
- cmd: `actlith pin [--dry-run]` → resolve ∀ action tag → full SHA via GitHub API; write `## actions` in `.actlith`. ONLY networked verb
- cmd: `actlith completions <shell>` · `actlith man`
- exit: 0 ok · 1 finding · 2 usage | unreadable | unknown kind/key/system | newer format
- file: `.actlith` → `format 1` line; `## workflows` `id|kind|systems|cache|args`; `## actions` `action|version|sha` (overrides built-in pin table); `## hand-written` `path|reason`; `## bots` `bot|args` (`src/bots`). `#` comments, `-` empty, `\|` literal pipe (pklith registry style)
- file: generated header `# generated by actlith gen from .actlith; do not edit`
- kinds: contract per kind (triggers, permissions, jobs, steps, args, secrets) → `docs/KINDS.md` (human) & kind nodes §V (law)
- runners: `x86_64-linux` → `ubuntu-latest` · `aarch64-linux` → `ubuntu-24.04-arm` · `aarch64-darwin` → `macos-latest` · `x86_64-darwin` → refused (⊥ runner)
- secrets: `CACHIX_AUTH_TOKEN` (cache push); `args token=<SECRET>` optional for PR-opening kinds
- lib: `actlith` exposes registry parse, kind model & render for reuse (pklith)
- nix: `packages.<system>.default` = `actlith`. ⊥ own devShell builder (pklith `lib.devShell` owns it)
